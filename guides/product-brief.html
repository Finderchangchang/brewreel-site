AI 宣传片产品简报怎么写：可下载模板与餐饮示例

把卖什么、给谁看、真实卖点、价格条件和素材来源写清楚。提供空白 Markdown 模板和明确标为虚构的餐饮示例。

先拿一份能填的模板

下载空白产品简报模板（Markdown） · 下载虚构餐饮示例

这些文件用普通文本编辑器就能填写。填完交给模型时，同时提供 BrewReel 的 SKILL 和对应行业配方；模板本身不是可直接渲染的分镜 JSON。

1. 写清楚观众应该理解的动作

不要只写「做一个高级的宣传片」。先写观众是谁、遇到什么问题，以及「用户做什么 → 产品给出什么」。软件可以描述一次具体操作；门店可以描述一次真实可提供的服务。

例如虚构餐饮示例写「顾客到店点选简餐 → 店员按菜单提供餐食」。它没有宣称排队更短、出餐更快或销量更高，因为示例没有这些证据。

2. 每个数字都带来源和完整条件

价格、时间、人数、效果百分比不能只给一个裸数字。写明原话、来源和适用条件。信息缺失就标「待确认」，不要把演示数字包装成商家经营成果。

不够完整的输入应该补什么
套餐 29 元包含什么、适用时间、是否券后、是否要预约、有无加价
节省一半时间测量对象、样本、时间段、对照方式和来源；没有就不写效果数字
顾客都说好获得使用许可的真实评价及出处；没有就不编评价

3. 素材说明要比文件名更清楚

给出文件、来源、使用授权、画面主体和希望突出的位置。门店照片与菜品照片可以标为商家实拍；软件截图是截图；插画和 AI 图片按实际性质说明，不能标成实拍。

没有照片时直接写「无」。BrewReel 可以按配方使用组件或插画兜底，但发布前仍要核对它是否会让观众误以为看到了真实商品或门店。

4. 片尾只放确实存在的获取方式

填写真实可用的行动入口，例如前往已上线官网、查看 GitHub 项目，或到实际存在的门店。未上线的渠道不要让模型补写；不知道就写「无」。

5. 交给模型前做一次自查

  1. 每个卖点都来自你提供的材料。
  2. 数字和条件没有彼此冲突。
  3. 虚构或演示数据已明确标注。
  4. 素材来源与可用范围可核对。
  5. 缺失信息写成「待确认」或「无」。

然后让模型生成分镜，运行项目校验，再渲染并人工看完整片。模板提高信息完整性，不代表获得平台审核或法律合规结论。

餐饮示例用于演示填写方法，店名、情境和内容都是虚构的，没有可对外出售的套餐。真实项目请以商家材料替换。字段依据：通用简报和餐饮简报。
